# Medora Global Education — Visual Refined

Premium multi-page React + Vite + Tailwind frontend.

## Run
```bash
npm install
npm run dev
```

## Frontend auth
Login and Sign Up are implemented with localStorage for now. Successful authentication opens the protected Home, Programs, Classes, Learning Models, Success Stories, About and Contact pages. Replace this demo layer with real backend/JWT authentication later.

## Design updates
- Roboto typography
- Lighter premium blue/cyan/violet palette
- Dribbble-inspired split hero with large education visual
- Slow image zoom + subtle floating cards
- Login / Sign Up entry flow
- Protected internal pages
